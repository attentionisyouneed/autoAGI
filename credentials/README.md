# 凭证图片放置说明

页面「获奖与证书」板块里的每一条都能点击查看原始凭证。把图片放进本目录（`credentials/`），
按下面的文件名命名，刷新页面即可自动显示——不需要改任何代码。

支持格式：`.jpg` / `.png` / `.jpeg` / `.webp`（按此顺序自动查找，找到哪个用哪个）

## 小提示

- 图片建议宽度 1200px 左右即可，过大会拖慢加载
- 涉及身份证号、家庭住址等信息时请先打码再上传（仓库是公开的）
- 某个凭证暂时没有图片也不用管：点开后会提示"尚未上传"，不会报错
- 想增删证书条目，改 `index.html` 里 `resume.certificates` 数组，本目录对应调整文件名即可
